# 亡灵杀手 · LowPoly 国风测试关

Three.js / Vite 开发的 WebGL 动作游戏。点击或拖动调整主角方向，前方接敌自动攻击，双击或 Space 翻滚。测试关包含三波敌人、远程兵与 Boss。

当前版本 **v0.15.0 · 原版风格五式重构**。双刀、砍刀和大刀采用用户提供源码的完整待机、走路、跑步和五式攻击曲线；大锤以原版骨盆、头和腿部动作及节奏为基础，自创五式宽幅抡击、腰肩发力和砸落回弹。人物持械时肩胯、头、双臂和腿部共同运动，攻击与恢复使用独立原式时钟。

四种兵器具有独立攻击与命中特效，沿实物刀刃或锤头运动：双刀交错宽弧、砍刀修长月牙、大刀厚重长斩弧、大锤实体锤头残影与风压碎甲。大锤击杀时打散敌人的真实身体与护甲模型；刀类沿实际挥刀平面切开敌人，切面封口、残体分离、落地淡出。特效观察原版伤害时钟，尾迹不会延长伤害；地面冲击只在真实锤头触地位置生成。音效包含20式独立挥击和命中、起手握柄、衣甲、脚步与腾身落地；刀刃金属声和大锤低沉石裂声各自调音，暂停与静音正确停止声音。原包没有音频文件，音效由本项目制作。动作来源、自创范围、骨架适配及验证依据见 [动作重构说明](docs/MOTION_REBUILD.md)。

## 运行

需要 Node.js 20 或更新版本：

```bash
npm ci
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

打开标题页“选择类型”，可查看四种武器的五式普攻，点击“再演一遍”重播。确认武器后进入战斗；暂停和结算页可以更换武器。手机建议横屏，并通过入口按钮请求全屏。

## 操作

- 点按地面或敌人：采样移动方向；按住或拖动持续调整方向，松手后减速。
- 前方接敌：自动转向起手，恢复阶段可以继续五式连击或接回移动。
- WASD / 方向键：移动。
- 双击 / Space：翻滚，消耗体力。
- P / Esc：暂停或继续。

## 检查

```bash
npm test
npm run build
```

当前测试覆盖原式五式时钟、走跑混合、完整骨骼姿态、自创大锤握点与锤头净空、暂停、切换、主角控制、发射器伤害和场景碰撞，以及四武器独立特效、真实模型切面封口、击杀碎片预算与资源释放。历史四式动作的断言保存在 `tests/legacy/`，由原式动作测试替代。

原始曲线数据的可复现导入与逐帧验证命令见 [src/sourceMotion/README.md](src/sourceMotion/README.md)。

开发分支为 `Undead-Slayer2`。部署与此前版本记录见 [docs/VALIDATION.md](docs/VALIDATION.md)，GitHub Pages 工作流位于 `.github/workflows/pages.yml`。
