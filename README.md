# 亡灵杀手 · LowPoly 国风测试关

使用 Three.js 与 Vite 开发的 WebGL 动作游戏。参考《亡灵杀手》点触移动、自动近战、点选追击与双击翻滚的核心体验，采用原创 LowPoly 国风美术，提供一个包含杂兵、远程敌人和Boss的测试关卡。

镜头采用参考原版截图的固定方向正交斜俯视，提供平滑移动起停与转向、按实际步距驱动的脚步、双刀、砍刀与大刀三种武器类型的四式普攻及命中后的移动衔接，并加入局部命中停顿、定向闪光与击退及按动作阶段触发的攻击音效。视角与战斗参数是本项目调校值。

双刀主角按用户提供的双刀刺客参考图采用低手蓄力站姿：双手位于大腿两侧，剑尖朝前下方，轻微前倾、屈膝，起跑沿用同方向低手持刀。待机以胸廓呼吸为主，重心偏向一条腿后稍作停留，肩臂放松并偶尔整握。移动时骨盆随落脚压低、蹬地回升，胸腔延迟反向扭转；肩、肘、腕分层走弧线，左右摆幅略有差异。起步前倾、停步回收时手臂延迟收势，转弯时头部先看向转向一侧，布片与马尾继续跟随。脚底通过三维逆向运动学保持落地，慢走步幅与实际移动距离匹配，急起步或转弯时按腿长修正骨盆高度。生产构建与浏览器检查结果见 [验证记录](docs/VALIDATION.md)。

大刀采用宽厚单刃和双手长柄，四式依次为踏步横扫、反向斜劈、回身大扫与踏地重劈。腰腿先带动肩臂，慢蓄势后快速挥斩，再保持持续收势；末式加强命中停顿与击退。命中使用实际刀刃的扫掠轨迹，双手在同一刀柄上保持0.22米握距。动作与参数为原创调校，公开参考与实现边界见 [大刀设计说明](docs/GREAT_DAO_DESIGN.md)。

敌人血条修正了黑底覆盖彩色血量的问题，按剩余生命比例从左侧缩短，归零立即隐藏；玩家与Boss界面血量同步限制在有效范围。此前持刀、血条比例与实际像素专项，以及25项交互回归均通过，详见验证记录。

## 本地运行

建议使用 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的地址。生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果输出到 `dist/`。浏览器需支持 WebGL；手机建议横屏游玩。

手机浏览器打开游戏后，首先显示“点击全屏 · 横屏进入”覆盖层。点击会请求全屏和横屏锁定；全屏且横屏后进入标题页，再点击“选择类型”选择双刀、砍刀或大刀。浏览器不支持或拒绝横屏锁定时，请打开自动旋转并将手机转为横向；退出全屏或转回竖屏后，可用提示中的按钮重新尝试。桌面和平板浏览器直接显示标题页。全屏需要由点击操作触发，且受浏览器支持和权限限制。

回归检查：

```bash
node --test tests/*.test.js
```

自动检查覆盖步态、待机、普攻接触窗口、动作衔接、接地、类型切换、攻击判定、特效与暂停等；具体覆盖范围以当前测试文件为准。浏览器中的类型选择、演武、战斗与手机布局需另行检查。

## 类型选择与普攻演武

标题页点击“选择类型”，提供双刀、砍刀与大刀三种武器类型。双刀使用双刃交替连斩，砍刀使用双手直刃挥砍，大刀使用重刃连续扫斩与踏地重劈。点击类型卡片更换持刀方式，并在中央播放四式普攻；“再演一遍”可重复观看。确认类型后开始战斗。

选择保存在当前浏览器中。暂停与胜败结算页的“换类型 · 重整出战”会回到类型选择并重置当前战场。手机横屏下，类型列表和详情可上下滚动。

目前只做普通攻击，没有武器技能、角色技能或魂力系统。

主角的近战控制保持稳定目标并在近敌时自动衔接连斩。点选远处敌人追击时，会顺路砍前方近敌并保留原锁定目标，继续向该目标推进；不会为侧后方临时目标绕路。点击地面、键盘移动和翻滚优先于自动追敌，翻滚撤离取消锁定。沿途攻击依据 Pocket Gamer 同期报道描述调校；具体目标选择与衔接规则属于本项目实现，公开资料未证明原版的精确AI算法或自动防御行为。

## 操作

- 点击或轻触地面：移动到目标位置。
- 点击敌人：锁定追击，接近后自动衔接四式普攻。
- 双击地面 / Space：翻滚闪避；双击撤离会取消锁敌。
- WASD / 方向键：移动。
- P / Esc 或暂停按钮：暂停或继续。
- 暂停与结算页可重试或更换类型。

## 测试关目标

三波共36名敌人（含Boss），清空敌人即可胜利。三星分别对应全灭、180秒内完成、受击不超过两次。此前双刀与砍刀版本的63项自动检查、2,196个姿态对拍、八段真实普攻伤害及19项生产浏览器流程检查为历史结果；新增大刀与主角控制调整的检查和发布状态以 [验证记录](docs/VALIDATION.md) 为准。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `src/weapons.js` | 双刀、砍刀与大刀类型、四式时序与战斗参数 |
| `src/choreography/greatDao.js` | 大刀四式刀路、双手握点、腰腿姿态与踏步时序 |
| `src/weaponModels.js` / `src/weaponMotion.js` | 持刀模型、姿态与普攻动作 |
| `src/weaponCombat.js` / `src/weaponEffects.js` | 普攻命中判定与刀光效果 |
| `src/characters.js` | 角色骨架、步态、接地与类型切换 |
| `src/main.js` | 类型演示、战斗状态、普攻命中、敌人与关卡循环 |
| `src/ui.js` / `src/style.css` | 标题、类型选择、战斗界面与响应式布局 |
| `src/fullscreen.js` | 手机启动全屏与横屏请求 |
