# 亡灵杀手 · LowPoly 国风测试关

使用 Three.js 与 Vite 开发的 WebGL 动作游戏。参考《亡灵杀手》点触移动、自动近战、点选追击与双击翻滚的核心体验，采用原创 LowPoly 国风美术，提供一个包含杂兵、远程敌人和Boss的测试关卡。

镜头采用参考原版截图的固定方向正交斜俯视，提供平滑移动起停与转向、按实际步距驱动的脚步、四段连续挥砍及命中后的移动衔接，并加入局部命中停顿、定向闪光与击退及按动作阶段触发的技能音效。视角与战斗参数是本项目调校值。

主角按用户提供的双刀刺客参考图采用低手蓄力站姿：双手位于大腿两侧，剑尖朝前下方，轻微前倾、屈膝，起跑沿用同方向低手持刀。待机以胸廓呼吸为主，重心偏向一条腿后稍作停留，肩臂放松并偶尔整握。移动时骨盆随落脚压低、蹬地回升，胸腔延迟反向扭转；肩、肘、腕分层走弧线，左右摆幅略有差异。起步前倾、停步回收时手臂延迟收势，转弯时头部先看向转向一侧，布片与马尾继续跟随。脚底通过三维逆向运动学保持落地，慢走步幅与实际移动距离匹配，急起步或转弯时按腿长修正骨盆高度。生产构建与浏览器检查结果见 [验证记录](docs/VALIDATION.md)。

敌人血条修正了黑底覆盖彩色血量的问题，按剩余生命比例从左侧缩短，归零立即隐藏；玩家与Boss界面血量同步限制在有效范围。此前持刀、血条比例与实际像素专项，以及25项交互回归均通过，详见验证记录。

## 本地运行

建议使用 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的地址。生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果输出到 `dist/`。浏览器需支持 WebGL；手机建议横屏游玩。

手机浏览器点击“拔刀入阵”或“重新入阵”时会自动尝试全屏，桌面和平板浏览器保持原来的显示方式。全屏受浏览器支持和权限限制；不支持或拒绝请求时仍可正常游玩。

动作回归检查：`node --test tests/characters.test.js`，8项检查覆盖全身步态、支撑脚接地、待机、暂停冻结、启停回收、低手摆臂和转向视线。

## 操作

- 点击或轻触地面：移动到目标位置。
- 点击敌人：追击目标；接近敌人后自动普通攻击。
- 双击地面：向目标方向翻滚。
- 点击技能按钮：施放技能。
- 使用暂停按钮暂停战斗，结算后可重新挑战。

桌面键盘便利操作：

| 按键 | 动作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Space | 翻滚 |
| 1–5 | 五种技能 |
| Q / E / R | 战骑 / 猎鹰 / 援军 |
| P / Esc | 暂停或继续 |

键盘支持是浏览器版新增功能。战骑、猎鹰和援军每场各可使用一次；技能消耗魂力，可拾取魂力补给继续施放。双击撤离会取消当前锁敌。

## 测试关目标

测试关包含三波、共36名敌人（含Boss）。清空敌人即可胜利；三星分别对应全灭、180秒内完成、受击不超过两次。普通近战采用四段双刃快斩，配合五种主动技能。这些连招、技能配置与数值属于本原型的设计参数。

生产构建与25项浏览器检查已通过，覆盖核心操作、技能、支援、三波胜败及模拟触屏布局。详见 [docs/VALIDATION.md](docs/VALIDATION.md)。GitHub Pages 已发布，并完成 HTTPS 资源一致性与浏览器交互核对。

## GitHub Pages

开发分支为 `Undead-Slayer2`。推送该分支会触发 `.github/workflows/pages.yml`，使用 Node.js 22 安装依赖，以 `/KenShi/` 为资源前缀构建并上传 Pages 产物，供检查；推送本身不发布站点。

发布通过 `main` 分支上的同名工作流手动触发，`source_ref` 默认填 `Undead-Slayer2`，也可以填写完整40位提交哈希；短提交号可能被 checkout 当作分支名。工作流构建该来源后，从 `main` 运行部署任务，以符合现有 `github-pages` 环境的分支策略。只有 `main` 上的手动运行执行部署。仓库 Pages 使用 GitHub Actions 工作流模式。
