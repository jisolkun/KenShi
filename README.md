# 亡灵杀手 · LowPoly 国风测试关卡

使用 HTML + Three.js 制作的浏览器动作原型：点击移动和追击、自动攻击、双击翻滚，以及三波敌人与Boss的单关测试。支持鼠标和触屏。开发模型：`gpt-6.1-sol`；开发分支：`Undead-Slayer`。

[手机触控画面](docs/mobile.png)

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的地址。生产构建和玩法验证：

```bash
npm run build
npm test
```

`npm test` 自动启动测试服务，使用系统 Chromium；可通过环境变量 `CHROMIUM_PATH` 指定浏览器路径，`TEST_PORT` 调整测试端口，`TEST_URL` 复用已启动的服务。验收包含桌面和手机交互，以及通过真实战斗清除三波敌人与Boss。

已通过18项自动验收，包括三波、19次击杀、Boss通关与三星结算。测试截图自动输出到 `test-results/`。

## 操作

- 点击地面：移动，自动斩击附近敌人。
- 点击敌人：追击并攻击目标。
- 双击地面：朝该方向翻滚闪避。
- 滑动屏幕：发动终结攻击，成功击杀可回复生命。
- 长按屏幕：蓄力发动EX攻击。
- 点击技能按钮，或按 `Q` / `E` / `R` / `F` / `C`：释放对应技能。
- 使用屏幕按钮暂停游戏或切换声音。

清除三波敌人并击败Boss即可通关。三星目标为通关、180秒内完成、受击少于2次；结算后可重新挑战。

五个技能以“突进、旋风、爆发、冰牢、飞刃”描述原型中的攻击和控制机制，这些名称不是经核实的原版技能名。

划屏瞬杀独立于 `R` 技能；各动作数值为本测试关卡设定。
