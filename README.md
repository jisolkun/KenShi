# 亡灵杀手 · LowPoly 国风测试关

Three.js / Vite 开发的 WebGL 动作游戏。点击或拖动调整主角方向，前方接敌自动攻击，双击或 Space 翻滚。测试关包含三波敌人、远程兵与 Boss。

当前版本 **v0.17.0 · 旋锤破阵**，提供双刀、砍刀、大刀和大锤四种兵器。三类刀使用上传源码的五式曲线；新大锤独立设计“旋身横破 → 回风挑岳 → 腾岳震阵”三连击，参考原版大幅全身转动、交叉换步、冲量前进与短促爆发的动作风格；大锤跑走采用原版刀系下肢曲线，独立制作双手持锤上身和腾身攻击。双手握住同一根刚性锤柄，实际锤头驱动扫掠碰撞、命中方向与反馈。

四种兵器具有独立攻击与命中特效：双刀交错宽弧、砍刀修长月牙、大刀厚重长斩弧、大锤蓝白横扫、青白挑转、金白重砸的宽幅能量挥面、亮边、速度流线和命中光环。末式在实际锤头触地后产生双层冲击圈、裂纹、尘土和碎石；跑动还有脚下速度反馈。刀击沿实际挥刀平面切开敌人；锤击致命时将当前模型破碎成独立实体块，局部散落后回收。特效尾迹不会延长伤害。18式挥击和命中分别调音，暂停与静音正确停止声音。原包没有音频文件，音效由本项目制作。新锤设计与源码依据见 [大锤三连击](docs/CUSTOM_HAMMER.md)，原式骨架适配见 [动作重构说明](docs/MOTION_REBUILD.md)。

## 运行

需要 Node.js 20 或更新版本：

```bash
npm ci
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

打开标题页“选择类型”，可查看四种武器的普攻演武：刀类五式、大锤三式，点击“再演一遍”重播。确认武器后进入战斗；暂停和结算页可以更换武器。手机建议横屏，并通过入口按钮请求全屏。

## 操作

- 点按地面或敌人：采样移动方向；按住或拖动持续调整方向，松手后减速。
- 前方接敌：自动转向起手，恢复阶段可以继续所选武器的连击或接回移动。
- WASD / 方向键：移动。
- 双击 / Space：翻滚，消耗体力。
- P / Esc：暂停或继续。

## 检查

```bash
npm test
npm run build
```
