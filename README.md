# 亡灵杀手 · LowPoly 国风测试关

Three.js / Vite 开发的 WebGL 动作游戏。点击或拖动调整主角方向，前方接敌自动攻击，双击或 Space 翻滚。测试关包含三波敌人、远程兵与 Boss。

当前版本 **v0.14.1 · 动作与音效**。双刀、砍刀和大刀采用用户提供源码的完整待机、走路、跑步和五式攻击曲线；大锤按原版全身动作与节奏自创五式抡击。人物持械时肩胯、头、双臂和腿部共同运动，攻击与恢复使用独立原式时钟。

刀光与伤害共享原版四帧时序，双刀具有独立主、副刀光；地面冲击、受击闪光、血花和镜头位移同步触发。音效包含20式独立挥击和命中、起手握柄、衣甲、脚步与腾身落地；刀刃金属声和大锤低沉石裂声各自调音，暂停与静音正确停止声音。原包没有音频文件，音效由本项目制作。动作来源、自创范围、骨架适配及验证依据见 [动作重构说明](docs/MOTION_REBUILD.md)。

## 运行

需要 Node.js 20 或更新版本：

```bash
npm ci
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

打开标题页“选择类型”，可查看四种武器的五式普攻，点击“再演一遍”重播。确认武器后进入战斗；暂停和结算页可以更换武器。手机建议横屏，并通过入口按钮请求全屏。

## 操作

- 点按地面或敌人：采样移动方向；按住或拖动持续调整方向，松手后减速。
- 前方接敌：自动转向起手，恢复阶段可以继续五式连击或接回移动。
- WASD / 方向键：移动。
- 双击 / Space：翻滚，消耗体力。
- P / Esc：暂停或继续。

## 检查

```bash
npm test
npm run build
```

当前测试覆盖原式五式时钟、走跑混合、完整骨骼姿态、自创大锤握点与锤头净空、暂停、切换、主角控制、发射器伤害和场景碰撞。历史四式动作的断言保存在 `tests/legacy/`，由原式动作测试替代。

原始曲线数据的可复现导入与逐帧验证命令见 [src/sourceMotion/README.md](src/sourceMotion/README.md)。

开发分支为 `Undead-Slayer2`。部署与此前版本记录见 [docs/VALIDATION.md](docs/VALIDATION.md)，GitHub Pages 工作流位于 `.github/workflows/pages.yml`。
