# 亡灵杀手 · LowPoly 国风测试关

使用 Three.js 与 Vite 开发的 WebGL 动作游戏。参考《亡灵杀手》点触方向输入、前方接敌自动攻击与双击翻滚的核心体验，采用原创 LowPoly 国风美术，提供一个包含杂兵、远程敌人和Boss的测试关卡。

镜头采用参考原版截图的固定方向正交斜俯视，提供平滑移动起停与转向、按实际步距驱动的脚步、双刀、砍刀、大刀与大锤四种武器类型的四式普攻及命中后的移动衔接，并加入局部命中停顿、定向闪光与击退及按动作阶段触发的攻击音效。视角与战斗参数是本项目调校值。

双刀主角按用户提供的双刀刺客参考图采用低手蓄力站姿：双手位于大腿两侧，剑尖朝前下方，轻微前倾、屈膝，起跑沿用同方向低手持刀。待机以胸廓呼吸为主，重心偏向一条腿后稍作停留，肩臂放松并偶尔整握。移动时骨盆随落脚压低、蹬地回升，胸腔延迟反向扭转；肩、肘、腕分层走弧线，左右摆幅略有差异。起步前倾、停步回收时手臂延迟收势，转弯时头部先看向转向一侧，布片与马尾继续跟随。脚底通过三维逆向运动学保持落地，慢走步幅与实际移动距离匹配，急起步或转弯时按腿长修正骨盆高度。生产构建与浏览器检查结果见 [验证记录](docs/VALIDATION.md)。

当前界面版本为 **v0.13.3 · 原式控制**。大锤四式沿用真实锤头轨迹命中，并在释放时加入竖向宽弧、白色核心、命中星芒、冲击波、尘屑和延迟低频回响；终结式会放大弧光与受击反馈。主角普通控制根据上传的参考代码包适配：点击采样地面方向，按住或拖动持续调整方向，松手后速度逐渐衰减；前方武器传感器接敌时自动起手，攻击恢复后可继续接招。当前双刀、砍刀、大刀与大锤仍使用本项目四式动作和真实兵器轨迹命中，原包五式、技能和跑攻未移植。验证记录见 [docs/VALIDATION.md](docs/VALIDATION.md)。

大刀四式“踏步横扫→反向斜劈→回身大扫→踏地重劈”现在由脚步、骨盆、胸躯和双臂共同带动，横扫跨过身体两侧，末式从过顶蓄势落到低位拖刀收势；实际刀尖扫掠、刀光、命中血花和场景碎屑使用同一条物理刀路。双脚按实际移动交替保持世界支撑锚点，步幅受敌人、障碍和场地边界限制；方向输入在攻击恢复时接回移动，翻滚按状态允许打断。演武同样连续向前走，“再演一遍”回到演武起点。

大刀重做为灰蓝钢面、连续弯尖、窄银刃、铜护手和暗色缠柄，轮廓收窄并保留厚刀背。双手保持0.22米握距，腰腿和胸躯带刀，前式末端接续下一式；慢蓄势后集中快斩，末刀低位重劈。四式仍为0.56、0.52、0.50、0.68秒，合计2.26秒；命中不冻结主角的挥砍，反馈由小兵硬直、末击击飞、血花、刀光与场景碎屑承担。

实际刀路同时驱动命中、刀光和环境反馈：气流扬起尘叶，碰到石灯、石块或石狮才放出接触碎屑与火星，末式近地留下短暂斩痕，石质实体保留。动作、模型与反馈资源为原创；设计见 [大刀说明](docs/GREAT_DAO_DESIGN.md)，实际观看的原版录屏时间段及技能/普攻边界见 [视频研究](docs/GREAT_DAO_VIDEO_REFERENCE.md)，未宣称原版精确四连或算法复刻。

敌人血条修正了黑底覆盖彩色血量的问题，按剩余生命比例从左侧缩短，归零立即隐藏；玩家与Boss界面血量同步限制在有效范围。此前持刀、血条比例与实际像素专项，以及25项交互回归均通过，详见验证记录。

## 本地运行

建议使用 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的地址。生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果输出到 `dist/`。浏览器需支持 WebGL；手机建议横屏游玩。

手机浏览器打开游戏后，首先显示“点击全屏 · 横屏进入”覆盖层。点击会请求全屏和横屏锁定；全屏且横屏后进入标题页，再点击“选择类型”选择双刀、砍刀、大刀或大锤。浏览器不支持或拒绝横屏锁定时，请打开自动旋转并将手机转为横向；退出全屏或转回竖屏后，可用提示中的按钮重新尝试。桌面和平板浏览器直接显示标题页。全屏需要由点击操作触发，且受浏览器支持和权限限制。

回归检查：

```bash
node --test tests/*.test.js
```

自动检查覆盖步态、待机、普攻接触窗口、动作衔接、接地、类型切换、攻击判定、特效与暂停等；具体覆盖范围以当前测试文件为准。浏览器中的类型选择、演武、战斗与手机布局需另行检查。

## 类型选择与普攻演武

标题页点击“选择类型”，提供双刀、砍刀、大刀与大锤四种武器类型。双刀使用双刃交替连斩，砍刀使用双手直刃挥砍，大刀使用重刃连续扫斩与踏地重劈，大锤使用双手抡击、上挑、回身扫锤与过顶砸地。点击类型卡片更换持刀方式，并在中央播放四式普攻；“再演一遍”可重复观看。确认类型后开始战斗。

选择保存在当前浏览器中。暂停与胜败结算页的“换类型 · 重整出战”会回到类型选择并重置当前战场。手机横屏下，类型列表和详情可上下滚动。

目前只做普通攻击，没有武器技能、角色技能或魂力系统。

普通主角控制沿用参考包的方向采样、速度衰减、前方接敌和连招窗口语义。点击敌人与点击地面都采样落点方向，主角按该方向移动；松手后的移动由方向和衰减速度驱动，落点只用作标记。前方传感器接敌时，主角转向该敌人并自动出招，攻击恢复后重新检测前方敌人。四式衔接由连招窗口决定；没有持续锁敌或自动追击移动目标。源码依据和适配边界见 [主角控制说明](docs/HERO_AI_REFERENCE.md)。

## 操作

- 点击或轻触地面、敌人：采样地面落点方向，朝该方向移动。
- 按住或拖动：持续调整移动方向；松手后速度逐渐衰减。
- 前方接敌：自动转向出招，按连招窗口衔接四式普攻。
- 双击地面 / Space：翻滚闪避，消耗体力。
- WASD / 方向键：移动。
- P / Esc 或暂停按钮：暂停或继续。
- 暂停与结算页可重试或更换类型。

## 测试关目标

三波共36名敌人（含Boss），清空敌人即可胜利。三星分别对应全灭、180秒内完成、受击不超过两次。此前双刀与砍刀版本的63项自动检查、2,196个姿态对拍、八段真实普攻伤害及19项生产浏览器流程检查为历史结果；新增大刀与主角控制调整的检查和发布状态以 [验证记录](docs/VALIDATION.md) 为准。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `src/weapons.js` | 双刀、砍刀、大刀与大锤类型、四式时序与战斗参数 |
| `src/choreography/greatDao.js` | 大刀四式刀路、双手握点、腰腿姿态与踏步时序 |
| `src/choreography/greatHammer.js` | 大锤原创四式时序、双手握点、身体转动及锤头净空 |
| `src/greatDaoMovement.js` | 大刀/大锤实际前踏与换侧推进、敌距和连续障碍/边界限制 |
| `src/weaponModels.js` / `src/weaponMotion.js` | 持刀模型、姿态与普攻动作 |
| `src/weaponCombat.js` / `src/weaponEffects.js` | 真实刀刃/锤头扫掠命中与斩击/钝击反馈 |
| `src/worldCombat.js` | 实际兵器轨迹驱动场景接触、近地斩痕与砸地尘浪 |
| `src/characters.js` | 角色骨架、步态、接地与类型切换 |
| `src/main.js` | 类型演示、战斗状态、普攻命中、敌人与关卡循环 |
| `src/referenceHeroControl.js` | 参考包普通主角方向采样、速度衰减、状态门槛与连招控制适配 |
| `src/heroAI.js` | 前方攻击传感器、攻击方向门槛与场地投影辅助 |
| `src/ui.js` / `src/style.css` | 标题、类型选择、战斗界面与响应式布局 |
| `src/fullscreen.js` | 手机启动全屏与横屏请求 |
