# 亡灵杀手 · LowPoly 国风测试关

Three.js / Vite 开发的 WebGL 动作游戏。点击或拖动调整主角方向，前方接敌自动攻击，双击或 Space 翻滚。测试关包含三波敌人、远程兵与 Boss。

当前版本 **v0.16.0 · 大锤三连击**，提供双刀、砍刀、大刀和大锤四种兵器。三类刀使用上传源码的五式曲线；新大锤独立设计“磐山横破 → 回峰挑击 → 落岳震阵”三连击，参考原版腰腿起力、短促释放与完整回收的动作风格。双手握住同一根刚性锤柄，实际锤头驱动扫掠碰撞、命中方向与反馈。

四种兵器具有独立攻击与命中特效：双刀交错宽弧、砍刀修长月牙、大刀厚重长斩弧、大锤实体头部残像与体积压力核。末式只在实际锤头触地后释放短尘屑与低频落锤声。刀击沿实际挥刀平面切开敌人；锤击将敌人击倒。特效尾迹不会延长伤害。18式挥击和命中分别调音，暂停与静音正确停止声音。原包没有音频文件，音效由本项目制作。新锤设计与源码依据见 [大锤三连击](docs/CUSTOM_HAMMER.md)，原式骨架适配见 [动作重构说明](docs/MOTION_REBUILD.md)。

## 运行

需要 Node.js 20 或更新版本：

```bash
npm ci
npm run dev
```

构建与预览：

```bash
npm run build
npm run preview
```

打开标题页“选择类型”，可查看四种武器的普攻演武：刀类五式、大锤三式，点击“再演一遍”重播。确认武器后进入战斗；暂停和结算页可以更换武器。手机建议横屏，并通过入口按钮请求全屏。

## 操作

- 点按地面或敌人：采样移动方向；按住或拖动持续调整方向，松手后减速。
- 前方接敌：自动转向起手，恢复阶段可以继续所选武器的连击或接回移动。
- WASD / 方向键：移动。
- 双击 / Space：翻滚，消耗体力。
- P / Esc：暂停或继续。

## 检查

```bash
npm test
npm run build
```

当前测试覆盖原式五式时钟、走跑混合、主角控制和发射器伤害；新大锤另验证双手刚性握点、实际身体网格净空、三击接势、30/60/120 Hz实物碰撞、收招脚步、暂停、反馈预算与资源释放。历史四式动作的断言保存在 `tests/legacy/`。

原始曲线数据的可复现导入与逐帧验证命令见 [src/sourceMotion/README.md](src/sourceMotion/README.md)。

开发分支为 `Undead-Slayer2`。部署与此前版本记录见 [docs/VALIDATION.md](docs/VALIDATION.md)，GitHub Pages 工作流位于 `.github/workflows/pages.yml`。
