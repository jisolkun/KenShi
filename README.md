# 亡灵杀手 · LowPoly 国风测试关

使用 Three.js 与 Vite 开发的 WebGL 动作游戏。参考《亡灵杀手》点触移动、自动近战、点选追击与双击翻滚的核心体验，采用原创 LowPoly 国风美术，提供一个包含杂兵、远程敌人和Boss的测试关卡。

本轮调整为参考原版截图的固定方向正交斜俯视，增强移动起停与转向过渡、按实际步距驱动的脚步、四段连续挥砍及命中后的移动衔接，并加入局部命中停顿、定向闪光与击退及按动作阶段触发的技能音效。视角与战斗参数是本项目调校值；本轮浏览器回归结果以验证记录为准。

待机新增胸肩呼吸、轻微重心转移、警觉观察与低频整握动作，脚底通过逆向运动学保持落地；布片与马尾在动作结束后逐渐恢复。敌人步态同样随实际步距推进，镜头跟随在本帧移动后更新，结算时角色自然收势并让残留特效消退。本轮回归尚未完成，历史验证记录不代表这些新增项已经全部通过。

## 本地运行

建议使用 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的地址。生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果输出到 `dist/`。浏览器需支持 WebGL；手机建议横屏游玩。

## 操作

- 点击或轻触地面：移动到目标位置。
- 点击敌人：追击目标；接近敌人后自动普通攻击。
- 双击地面：向目标方向翻滚。
- 点击技能按钮：施放技能。
- 使用暂停按钮暂停战斗，结算后可重新挑战。

桌面键盘便利操作：

| 按键 | 动作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Space | 翻滚 |
| 1–5 | 五种技能 |
| Q / E / R | 战骑 / 猎鹰 / 援军 |
| P / Esc | 暂停或继续 |

键盘支持是浏览器版新增功能。战骑、猎鹰和援军每场各可使用一次；技能消耗魂力，可拾取魂力补给继续施放。双击撤离会取消当前锁敌。

## 测试关目标

测试关包含三波、共36名敌人（含Boss）。清空敌人即可胜利；三星分别对应全灭、180秒内完成、受击不超过两次。普通近战采用四段双刃快斩，配合五种主动技能。这些连招、技能配置与数值属于本原型的设计参数。

生产构建与25项浏览器检查已通过，覆盖核心操作、技能、支援、三波胜败及模拟触屏布局。详见 [docs/VALIDATION.md](docs/VALIDATION.md)。GitHub Pages 已发布，并完成 HTTPS 资源一致性与浏览器交互核对。
