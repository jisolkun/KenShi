# 亡灵杀手 · LowPoly 国风测试关

使用 Three.js 与 Vite 开发的 WebGL 动作游戏。参考《亡灵杀手》点触移动、自动近战、点选追击与双击翻滚的核心体验，采用原创 LowPoly 国风美术，提供一个包含杂兵、远程敌人和Boss的测试关卡。

镜头采用参考原版截图的固定方向正交斜俯视，提供平滑移动起停与转向、按实际步距驱动的脚步、每种兵器各自的四式连招及命中后的移动衔接，并加入局部命中停顿、定向闪光与击退及按动作阶段触发的技能音效。视角与战斗参数是本项目调校值。

主角按用户提供的双刀刺客参考图采用低手蓄力站姿：双手位于大腿两侧，剑尖朝前下方，轻微前倾、屈膝，起跑沿用同方向低手持刀。待机以胸廓呼吸为主，重心偏向一条腿后稍作停留，肩臂放松并偶尔整握。移动时骨盆随落脚压低、蹬地回升，胸腔延迟反向扭转；肩、肘、腕分层走弧线，左右摆幅略有差异。起步前倾、停步回收时手臂延迟收势，转弯时头部先看向转向一侧，布片与马尾继续跟随。脚底通过三维逆向运动学保持落地，慢走步幅与实际移动距离匹配，急起步或转弯时按腿长修正骨盆高度。生产构建与浏览器检查结果见 [验证记录](docs/VALIDATION.md)。

敌人血条修正了黑底覆盖彩色血量的问题，按剩余生命比例从左侧缩短，归零立即隐藏；玩家与Boss界面血量同步限制在有效范围。此前持刀、血条比例与实际像素专项，以及25项交互回归均通过，详见验证记录。

## 本地运行

建议使用 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的地址。生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果输出到 `dist/`。浏览器需支持 WebGL；手机建议横屏游玩。

手机浏览器打开游戏后，首先显示“点击全屏 · 横屏进入”覆盖层。点击会请求全屏和横屏锁定；全屏且横屏后进入标题页，再点击“选兵入阵”选择兵器。浏览器不支持或拒绝横屏锁定时，请打开自动旋转并将手机转为横向；退出全屏或转回竖屏后，可用提示中的按钮重新尝试。桌面和平板浏览器直接显示标题页。全屏需要由点击操作触发，且受浏览器支持和权限限制。

回归检查：

```bash
node --test tests/*.test.js
```

检查覆盖原有步态与待机、27种兵器的108个连招接触窗口、四式动作差异、双手握持衔接、脚底接地、切换装备、攻击范围与方向、特效几何、暂停冻结和对象复用。浏览器中的选兵、演武、战斗与手机布局还需按 [验证记录](docs/VALIDATION.md) 检查；具体实测结果以该记录为准。

## 选兵与演武

标题页点击“选兵入阵”打开兵器谱，可按“刀剑 / 长兵 / 重兵 / 奇门”筛选。点击兵器卡片更换角色手中模型，并在中央演武区播放该兵器的四式连招；“再演一遍”可重复观看。右侧显示攻击风格、速度、威力、距离以及四式名称。点击“携某兵器入阵”才开始战斗。

选择会保存在当前浏览器中，重新入阵沿用所选兵器。暂停和胜败结算页的“换兵器 · 重整出战”会回到兵器谱并重置当前战场。手机横屏下，兵器列表和详情可分别上下滚动。

兵器谱收录27件兵器，目前开放双刀、唐刀和雁翎刀，其余24件显示锁定。五个技能按钮随装备显示相应名称。双刀使用历史攻击动作；唐刀采用双手长柄、大幅斜斩、横斩、上撩及落劈；雁翎刀采用右手单刀、独立左手收展、横抹、低撩、斜落、撤步反切与窄线点刺。唐刀和雁翎刀的命中使用实际三维刀刃，刀光跟随同一刀路，多段分别判定；雁翎刀点刺仅扫实际弯尖。设计依据与逐招审核见 [唐刀设计](docs/TANG_DAO_REDESIGN.md)、[雁翎刀设计](docs/YANLING_DAO_REDESIGN.md)及[验证记录](docs/VALIDATION.md)。以下为兵器目录，锁定项目不能入阵。

## 操作

- 点击或轻触地面：移动到目标位置。
- 点击敌人：追击目标；接近敌人后自动普通攻击。
- 双击地面：向目标方向翻滚。
- 点击技能按钮：施放技能。
- 使用暂停按钮暂停战斗，结算后可重新挑战。

桌面键盘便利操作：

| 按键 | 动作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Space | 翻滚 |
| 1–5 | 五种技能 |
| Q / E / R | 战骑 / 猎鹰 / 援军 |
| P / Esc | 暂停或继续 |

键盘支持是浏览器版新增功能。战骑、猎鹰和援军每场各可使用一次；技能消耗魂力，可拾取魂力补给继续施放。双击撤离会取消当前锁敌。

## 测试关目标

测试关包含三波、共36名敌人（含Boss）。清空敌人即可胜利；三星分别对应全灭、180秒内完成、受击不超过两次。普通近战按所选兵器自动衔接四式连招，配合五种主动技能。这些连招、技能配置与数值属于本原型的设计参数。

当前雁翎刀版本通过195项自动检查及32项桌面／模拟手机流程检查，并逐招核对真实伤害与三视角动作。核心操作、支援和三波胜败的历史检查，以及本轮具体范围见 [docs/VALIDATION.md](docs/VALIDATION.md)。GitHub Pages 发布后核对线上与本地构建的资源一致性。

## 模块结构

| 文件 | 职责 |
| --- | --- |
| `src/weapons.js` | 27种兵器目录、属性、四式时序与战斗参数、技能名称 |
| `src/weaponModels.js` | 原创低多边形兵器模型、握持位置与刀尖节点 |
| `src/weaponMotion.js` | 各兵器四式动作、持兵姿态与动作衔接 |
| `src/choreography/` | 前五件独立技术轨迹、连续刃面采样、双手约束与脚步目标 |
| `src/weaponCombat.js` | 实体刃段扫掠、刀尖窄线，以及目录兵器的范围判定 |
| `src/weaponEffects.js` | 各兵器招式轨迹、接触与技能效果，以及特效对象复用 |
| `src/characters.js` | 角色骨架、步态、接地与装备切换 |
| `src/main.js` | 选兵演武、战斗状态、连招命中、敌人和关卡循环 |
| `src/ui.js` / `src/style.css` | 标题、兵器谱、战斗界面与响应式布局 |
| `src/fullscreen.js` | 手机启动全屏与横屏请求 |

## GitHub Pages

开发分支为 `Undead-Slayer2`。推送该分支会触发 `.github/workflows/pages.yml`，使用 Node.js 22 安装依赖，以 `/KenShi/` 为资源前缀构建并上传 Pages 产物，供检查；推送本身不发布站点。
