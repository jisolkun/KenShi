# 双刀恢复与唐刀重新设计

本轮依据用户反馈撤回 `512f1c6` 的双刀重构，并替换唐刀的胸前短幅动作。仅开放双刀和唐刀，其余25种兵器保留图鉴并锁定，暂不作为已打磨完成的动作交付。

## 调研依据

- [尹玉章《砍刀术练习法》（1933），原文与译文](https://brennantranslation.wordpress.com/2016/06/17/yin-yuzhangs-saber-manual/)：挂砍、剁刀、撩刀均明确配合迈步、转腰与落步。
- [陈炎林《太极拳刀剑杆散手合编》（1943）刀卷，原文与译文](https://brennantranslation.wordpress.com/2012/11/30/yang-style-taiji-saber/)：强调“皆以腰腿为主动枢纽”“周身一致”，并要求撩刀时肘勿过直。
- [Met 中国佩刀实物](https://www.metmuseum.org/art/collection/search/22412)：18世纪末至19世纪，刃长73cm、总长87.6cm。这是近代单手佩刀尺度参考，不能作为唐代长柄刀史证。

游戏采用现代艺术化的长柄直身单刃唐刀造型，动作参考上述刀术的全身发力原则。模型尺度、转角和时间是游戏设计值；这些来源不证明唐代技法复原。

## 设计与播放

双刀恢复 `1c9c4da` 的燕返、交锋、穿花、双月及五个技能，取消替换它的动作注册和物理刀路覆盖，保留历史判定与反馈。

唐刀采用实际可双手握持的长柄。待机保持沉肩、屈肘、前下方低位持刀，胸部呼吸先于手与刀的轻微跟随。四段普攻分别为踏步斜斩、转胯横斩、提膝上撩、过顶落劈；技能连接这些刀路，保持蓄势、快速出刃、长程制动的节奏。

髋部与胸肩各有独立时间曲线，手与刀在角色空间编排后转换到胸部空间求解。刀尖扫过左右身侧，避免胸前画短弧。双手目标从同一刀柄轴派生；落步和承重在角色空间编排。宽幅有效窗口覆盖真实挥刀过程，逐帧以可见刀根至刀尖的扫掠检测伤害，刀光跟随同一条刀路。

## 验证

审核覆盖完整动作时间轴、正面／侧面／游戏俯视、状态过渡、双手握柄、脚步、刀刃净空与两侧敌人的实际命中。单靠接触点或数值检查不能证明动作自然，视觉问题仍需继续修正。最终验证结果记录于 [VALIDATION.md](VALIDATION.md)。
