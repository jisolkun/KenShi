# 前五件兵器动作重构（历史记录）

原记录日期：2026-10-09。

此记录对应 `512f1c6`，用户已反馈这些动作不符合要求。该版本的数值检查通过不代表视觉品质通过。当前双刀已恢复至 `1c9c4da` 历史动作，仅开放双刀与唐刀，其余兵器锁定；本轮设计见 [TANG_DAO_REDESIGN.md](TANG_DAO_REDESIGN.md)。

按兵器谱顺序逐件实施。每件完成后，由独立数值审核和多视角视觉审核确认，再进入下一件。

## 动作与判定

每招分别编排握柄位置、刀轴、刃面、腰胯、承重和回收。共享的轨迹插值及逆向运动学只负责连续播放与握持约束。切换招式前提前翻刃，避免在命中瞬间甩腕。

前五件的普通攻击和技能使用真实刀根至刀尖的三维扫掠，与敌人竖向碰撞体相交才造成伤害。刀光跟随同一刀刃，并只在该手有效攻击窗口显示；多段技能分别记录每段命中。直刺单独检查沿刀轴前送，劈切检查刃口与横向速度一致。

## 逐件审核记录

### 1. 双刀 — 通过

四式为右斜劈、左接斩、反手撩切、错锋双斩；左右手分别蓄势、出刃和回收。终式是错开的两次切击，技能也使用独立分段刀路。

修复初审发现的突然翻腕、刀背切入及实际播放速度下的刃面跳转。最终实际60Hz采样：最大单帧关节变化27.22°、刀刃世界姿态变化25.76°；有效劈切刃口与横向速度余弦至少0.984，刃面泄漏不超过0.178。刀尖最低0.061m；握柄误差在浮点精度范围内，身体净空和站立／移动腿链可达。

已审查正面、侧面和游戏俯视的蓄势、接触、随动及邻帧，真实游戏中确认普通攻击造成伤害、五个技能完成、暂停冻结和换兵返回。

### 2. 唐刀 — 通过

四式为短幅斜切、翻刃横截、前送直刺、中线落劈。右手独立持刀，左手保持肋前护位；模型改为单刃直背与斜尖。

独立实际60Hz采样：最大单帧关节变化18.04°、刀刃世界姿态变化17.78°；劈切刃口余弦至少0.987，刃面泄漏不超过0.163。三处直刺有效窗内刀轴前向余弦0.99698，横向漂移小于8mm。身体、空手、地面净空及站立／移动腿链通过。共享轨迹模块提取后，双刀60Hz数据保持一致。

普通攻击及五技能的正面、侧面、游戏俯视和邻帧视觉复审通过，未见护手被切、刀柄脱离或落劈穿身。真实游戏中确认普通攻击造成伤害、五个技能完成、暂停冻结和换兵返回。完成该件审核后进入第三件。

### 3. 雁翎刀 — 通过

四式为腰高横抹、低位撩锋、侧上斜落、抽步反切。撩锋使用明确的由低到高弧形切击；反切有后脚抬起撤步、落地承重和再次抬起归位的过程。

独立实际60Hz采样：最大单帧关节变化18.25°、刀刃世界姿态变化25.27°；劈切刃口余弦至少0.993，刃面泄漏不超过0.119。刀刃最低0.502m，握柄、身体及空手净空通过。抽步承重阶段脚目标固定，密集采样地面滑移在浮点精度范围内；站立与移动脚目标均可达。

已查看普通攻击、五技能的三视角关键帧、邻帧以及抽步序列，共13张接触表。侧面确认撩切由低至高，后脚撤步包含完整抬落；未见穿身、穿脚或突然翻腕。

### 4. 苗刀 — 通过

四式为双手踏步落劈、转胯宽横切、蹬步撩刀、中线长刺，五技能分别连接两到三段长刀技术。后手从最终刀轴派生，始终贴在长柄后段；状态混合保留主手刀轴，再对接后手。

独立实际60Hz采样：最大单帧关节变化15.91°、刀刃世界姿态变化13.04°；劈切刃口余弦至少0.996，刃面泄漏不超过0.094；长刺刀轴前向余弦至少0.9967。攻击刀刃最低0.583m。10,968帧待机／跑动与全部攻击、技能的过渡保持握柄接合，最终误差在浮点精度范围内。90,090个移动脚目标通过，最差可达余量18.34mm。

三视角普通攻击、五技能和邻帧，另加踏步序列与双手握柄放大图全部通过。前脚先抬起，再落地承重出刀，长刺保持同轴前送；未见长刃穿头、穿身或后手悬空。

### 5. 九环大刀 — 通过

四式为肩蓄宽横斩、举刀重劈、低位压刃斜削、沉身大斜劈。使用独立重刀轨迹、宽站距与较短踏步，蓄势和制动时间比苗刀更长。刀柄加长至48cm使后手握位落在实际柄内；九环分别悬挂，随世界重力和刀势滞后摆动。

独立实际60Hz采样：最大单帧关节变化18.26°、刀刃世界姿态变化18.21°；刃面泄漏不超过0.029。密集攻击与14,436帧状态过渡的刀刃最低均约0.497m，握柄误差在浮点精度范围内。入技能初审发现的约28mm穿地已通过整刀轴的位置与四元数混合修复。90,090个移动脚目标通过，最差可达余量48.62mm。实际刀尖在驱动段至制动段降速约94～95%，并非强行瞬间定格。

九环约527万个实际网格顶点的抽样净空、有限矩阵和连接检查通过。普通攻击与五技能三视角、邻帧、重劈脚序列、双手与九环放大图通过，另检查真实浏览器待机进入技能的12帧连续过渡，未见穿地或脱柄。

## 审核范围

移动攻击的步相按真实位移推进。修复了短步幅与原固定支撑时长不匹配导致的脚底滑移；雁翎刀移动混合另降低骨盆最多15mm，保持脚目标可达。前三件的9动作×5档移动混合×1001相位独立密采中，每件90,090个脚目标通过，最差腿长余量分别为9.64mm、10.40mm、7.44mm；支撑阶段世界脚漂移不超过3.56×10⁻¹⁵m。停步200ms后无持续悬脚。增加了动作相位与步态相位独立组合的持续回归，避免只沿一条时间线采样漏过边界。

数值审核以真实角色骨架与刀刃世界变换为依据，包含密集相位采样和按实际动作时长播放的60Hz采样。视觉审核使用软件WebGL的正面、侧面、游戏俯视以及邻帧接触表。记录验证动作方向、几何约束和交互；不等同于实体手机帧率或原版逐帧一致性。
