# 大锤 v0.10.0：狂锤破阵与动作参考

本轮依据用户上传的 `动作参考.rar`，读取其中 `代码/src/`、`说明/` 与 `视觉参考/`。包内文档作为动作研究资料；本轮功能要求来自用户提出的大锤重构。参考没有独立的大锤动作族，提供的是刀、枪戟、双刀、棍、弓及魔法动作。因此四式大锤的姿态、锤面轨迹、时长和反馈参数由本项目独立设计。

## 参考中可确认的动作风格

| 依据（参考包内路径） | 实现事实 | 本项目采用方式 |
| --- | --- | --- |
| `reference-motion.js`、`reference-player-stats.js`、`reference-control.js` | 攻击按 `.24 + atkspd` 播放，恢复另按 `.24`；普通恢复能重新进入移动控制门槛 | 普攻采用短起手与快速衔接，不以基准攻击加恢复时长推断实战出手间隔 |
| `reference-motion-data.js`、`reference-ordinary-animation.js` | 攻击与恢复分段，枪戟有五段攻击与各自恢复 | 保留起手、集中释放、惯性制动和下一式准备的分段差异 |
| `视觉参考/攻击与刀光/qa-swing-main-spear-3.png`、`reference-attack-rules.js` | QA 截图中的旋转斩包围角色形成大圈；对应攻击体世界半径约 3.3 米 | 身体转腰带动宽幅轮锤，并加入与显示边界一致的群体冲击 |
| `reference-curve-motion.js`、`视觉参考/动作时序/qa-action-charge-0.7.jpg`、`视觉参考/攻击与刀光/qa-swing-touch-heavy.png` | 髋、胸、手臂和武器共同变化；重击有屈膝下压、明显爆闪与放射地裂 | 脚步接住重心，腰胸带出大幅横扫，砸地瞬间集中释放尘石与冲击 |
| `reference-swing-feedback.js`、`reference-frame-clock.js` | 挥击显示为 20 fps 四帧，碰撞有效段约为显示后的 .05～.15 秒 | 动作、实际锤头碰撞、呼啸与残影共享动作时钟 |
| `reference-hit-feedback.js`、`reference-hit-glint.js` | 接触闪光与受击独立处理，重击层 21 使用闪光反馈 | 钝击亮核、短促尘屑、群体击退和压身受击叠层 |
| `reference-splash-clock.js` | 重击地裂显示 1.5 秒，碰撞段 .2 秒 | 实际锤头接地才释放一次范围冲击及 1.5 秒地裂；裂纹显示独立于伤害 |
| `reference-camera.js`、`reference-combat-audio.js` | 出招、挥击、接触及重击声分开，命中驱动镜头冲击 | 空挥呼啸，击中闷响，末式接地低频轰响；镜头沿真实击打方向响应 |

参考普通显示延迟还会减去 `atkspd`；总动作时长包含完整排队恢复，不能据此断言参考实战节奏缓慢。包内视觉文件是已有项目 QA 截图，无法仅凭静态截图测出原 Android 设备的连续攻速。参考普通刀光实际为根节点挂载的四帧平面；本项目的锤头残影使用实体实时轨迹。参考没有独立大锤动作族，也没有普通命中的正值停帧设置，本项目的四式、范围冲击和 12～28 毫秒局部顿挫均为原创调校。

## 独立四式

| 招式 | 时长 | 发力与武器轨迹 | 前进预算 |
| --- | ---: | --- | ---: |
| 横抡开阵 | .48 秒 | 短起手向右带锤，踏步转腰横抡至左侧，扫开前方敌群 | .46 米，右侧步 .20 米 |
| 斜砸碎石 | .46 秒 | 顺着横抡收势抬锤，转胯沉肩斜砸低位；实际接地释放碎石冲击 | .28 米，左侧步 .12 米 |
| 回身狂扫 | .56 秒 | 从左侧大幅拧腰回扫至右侧，身体与锤头共同打开宽扇面 | .54 米，左侧步 .24 米 |
| 震地破阵 | .68 秒 | 迅速高举重锤，屈膝下压砸地，释放更大的环向冲击后拔锤收势 | .30 米 |

四式合计 2.18 秒，上一版为 3.64 秒；空地前进总预算 1.58 米。每式都采用短起手、集中快抡和连续收势，扩大腰胯与胸躯转动，保持割草战斗的推进感。敌距、障碍和地图边界会缩短实际移动。每式根位移在有效接触前完成；支撑脚保持世界锚点，追击方向和转身由上方身体消化。上一式实物握柄和锤面收势直接承接下一式。

锤面使用独立稳定坐标架，斜砸与震地将端面转入纵向发力平面，横抡与回扫保持侧向锤面。大锤复用通用身体/握点插值，并独立求锤面方向，避免刀刃速度定向导致的手腕突转，也不构建刀刃边缘的 2000 帧滚转缓存。

## 实体与打击反馈

锤头尺寸 .54×.38×.38 米，右腕至锤心 1.25 米，双手握距 .22 米，腕后完整柄长 .31 米。握点同时受双臂可达范围、手掌和尾柄胸甲净空约束。完整旋转锤头保持在石铺地上方；接地判定仍读取实际锤头八角点最低高度。

窗口内实体锤头保留连续扫掠，水平半径 .27 米，垂直半高取真实旋转包围盒投影。另由 `src/hammerFeedback.js` 定义四式的明确范围冲击：横抡和回扫在动作接触相位释放扇面；斜砸和震地仅在实际锤头八角点接触地面后释放圆形冲击。

| 招式 | 冲击体 | 半径 | 半角 / 触发条件 |
| --- | --- | ---: | --- |
| 横抡开阵 | 前方扇面 | 2.65 米 | 半角 1.70 弧度，接触相位释放一次 |
| 斜砸碎石 | 接地点圆形 | 2.20 米 | 实际接地后释放一次 |
| 回身狂扫 | 宽扇面 | 3.00 米 | 半角 1.92 弧度，接触相位释放一次 |
| 震地破阵 | 接地点圆形 | 3.20 米 | 实际接地后释放一次 |

范围冲击具有独立高度限制，敌人身体半径参与边界重叠。特效与命中读取同一个冲击体，显示的扇面或圆圈边界对应实际伤害范围。实体锤头和范围冲击共享每式的敌人命中记录，同一敌人每式最多受伤一次；杆身和残影不会另外制造伤害。

快速释放时显示 100～120 毫秒的厚头部残影与宽面冲击；低速准备和回收不留下长刀月牙。命中处生成短促亮核和赭色尘屑，横抡、回扫与砸地使用不同方向和扩散。实际锤头水平运动控制实体接触的击退与镜头，圆形冲击使用目标相对接地点的径向击退。每式首次实际击中给予 12/14/18/28 毫秒局部接触顿挫，群体命中不叠加延长，保持快速连续挥锤。

第二式与末式真实接地才生成一次碎石弹起、扩散尘浪、冲击圈和 1.5 秒放射地裂，末式的范围与爆发更大。武器、粒子与音色由本项目制作，粒子使用固定实例池。移动、翻滚、暂停和重开继续按原有交互接管。验证与发布记录见 [VALIDATION.md](VALIDATION.md)。

大石、石灯和石狮保留独立的 `props.nodes`，不并入静态场景批次。实体锤头、扇面冲击或真实接地冲击波触石后，首次使实体压缩倾斜，累计第二次让石灯上部倒落散开，或将石块、整组石狮压成低矮残骸；每式对同一场景道具最多触发一次。破碎后的锤击碰撞体降至残骸高度，不留下空中灯柱；残骸保留原移动障碍圈，依旧阻挡移动。`clearCombat()` 按快照恢复全部节点的位移、旋转、缩放和可见性、原始碰撞体，并清除破损状态；这项实际改变场景实体，区别于短暂的碎石粒子。
