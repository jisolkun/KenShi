# 大锤 v0.9.0：动作参考与独立重构

本轮依据用户上传的 `动作参考.rar`，读取其中 `代码/src/`、`说明/` 与 `视觉参考/`。包内文档作为动作研究资料；本轮功能要求来自用户提出的大锤重构。参考没有独立的大锤动作族，提供的是刀、枪戟、双刀、棍、弓及魔法动作。因此四式大锤的姿态、锤面轨迹、时长和反馈参数由本项目独立设计。

## 参考中可确认的动作风格

| 依据（参考包内路径） | 实现事实 | 本项目采用方式 |
| --- | --- | --- |
| `reference-motion-data.js`、`reference-ordinary-animation.js` | 攻击与恢复分段，枪戟有五段攻击与各自恢复 | 起手、释放、惯性制动、下一式准备使用不同节奏 |
| `reference-attack-rules.js` | 枪戟基准攻击段约 .556/.833/.833/.556/1.250 秒，显示启动延迟各异 | 上挑更短，盘身更长，终式蓄势最明显 |
| `reference-curve-motion.js`、`视觉参考/动作时序/qa-action-charge-0.7.jpg` | 髋、胸、手臂和武器共同变化，重击有明显屈膝和下压 | 腿腰先接住重心，胸肩随后带动锤头 |
| `reference-swing-feedback.js`、`reference-frame-clock.js` | 挥击显示为 20 fps 四帧，碰撞有效段约为显示后的 .05～.15 秒 | 动作、实际锤头碰撞、呼啸与残影共享动作时钟 |
| `reference-hit-feedback.js`、`reference-hit-glint.js` | 接触闪光与受击独立处理，重击层 21 使用闪光反馈 | 小面积钝击亮核、定向尘屑与压身/仰身受击 |
| `reference-splash-clock.js` | 重击地裂显示 1.5 秒，碰撞段 .2 秒 | 真实接地生成一次地裂，保持 1 秒后用 .5 秒淡出；地裂仅为场景视觉 |
| `reference-camera.js`、`reference-combat-audio.js` | 出招、挥击、接触及重击声分开，命中驱动镜头冲击 | 空挥呼啸，击中闷响，末式接地低频轰响；镜头沿真实击打方向响应 |

上表的枪戟攻击段是参考基准数据，恢复时间和攻速另算，不是原版完整大锤时长。参考普通刀光实际为根节点挂载的四帧平面；本项目的锤头残影改用实体实时轨迹。参考没有普通命中的正值停帧设置，本项目 23～55 毫秒的局部顿挫是原创调校。

## 独立四式

| 招式 | 时长 | 发力与武器轨迹 | 前进预算 |
| --- | ---: | --- | ---: |
| 沉肩斜砸 | .80 秒 | 提至右肩上方，踏稳后转胯沉肩，沿陡斜面砸向前方低位 | .32 米，右侧步 .16 米 |
| 拔地挑锤 | .68 秒 | 承接低位，屈膝后伸腿拔锤上挑；伤害窗在实际上升之后打开 | .12 米 |
| 盘身摆锤 | .96 秒 | 接住上挑余势，拧腰带出一段宽水平摆击，随后提至肩上 | .40 米，左侧步 .18 米 |
| 顿足镇岳 | 1.20 秒 | 依次站稳双足，深蹲举锤，躯干下压砸地，短回弹后拔锤收势 | .26 米 |

四式合计 3.64 秒，空地前进总预算 1.10 米。敌距、障碍和地图边界会缩短实际移动。每式根位移在有效接触前完成；支撑脚保持世界锚点，追击方向和转身由上方身体消化。上一式实物握柄和锤面收势直接承接下一式。

锤面使用独立稳定坐标架，下砸与上挑将端面转入纵向发力平面，盘身摆击保持侧向锤面。大锤复用通用身体/握点插值，并独立求锤面方向，避免刀刃速度定向导致的手腕突转，也不再构建刀刃边缘的 2000 帧滚转缓存。

## 实体与打击反馈

锤头尺寸 .54×.38×.38 米，右腕至锤心 1.25 米，双手握距 .22 米，腕后完整柄长 .31 米。握点同时受双臂可达范围、手掌和尾柄胸甲净空约束。完整旋转锤头保持在石铺地上方；接地判定仍读取实际锤头八角点最低高度。

伤害只检查窗口内实体锤头的连续扫掠，水平半径 .27 米，垂直半高取真实旋转包围盒投影。这是紧凑圆柱碰撞原型，杆身和残影不扩展伤害范围。每段对每个敌人最多命中一次。

快速释放时显示 85～115 毫秒的短厚头部残影；低速蓄势和回收不留下长刀月牙。命中处生成短促亮核和赭色尘屑，横摆、上挑、下砸使用不同方向和扩散。实际锤头水平运动控制击退与镜头，近乎垂直时使用目标径向退让；锤头上下运动控制敌人仰身或压身。每式首次实际击中给予 30/23/38/55 毫秒局部接触顿挫，群体命中不叠加延长。

末式锤头真实接近地面才生成一次紧凑尘石、冲击圈和 1.5 秒地裂。武器、粒子与音色由本项目制作，采用固定实例池并保持现有资源预算。移动、翻滚、暂停和重开继续按原有交互接管。验证与发布记录见 [VALIDATION.md](VALIDATION.md)。
