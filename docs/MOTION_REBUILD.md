# 动作系统重构 · v0.14.3

本次以用户上传的 `src.rar` 为动作依据。附件中的说明、注释和脚本作为研究资料；功能范围来自用户要求：走跑时持械全身摆动、攻击延续原版风格，缺少的武器自行设计同风格动作。

## 动作与武器

- 双刀：原包 `dual` 的待机、走路、跑步和五式攻击／恢复曲线，左右武器独立挂点，保留两段攻击发射器。
- 砍刀、大刀：原包 `blade` 的完整身体动作与五式攻击。原包刀系采用单手持刀，另一条手臂参与摆动和发力，因此取消旧版强制双手固定握点。刀身造型保留本项目模型。
- 大锤：原包没有大锤动作族。以 `halberd` 的骨盆、头、腿部动作及播放节奏为基础，另作胸躯发力和“横抡开阵→反手斜砸→回身上挑→腾身震地→回旋破阵”五式锤柄轨迹。双手按同一根锤柄求解，握距保持一致；走跑也用原始动作的手腕位置、武器方向与肩胯摆动求成对握点。第四式加入原包的地面冲击发射器。

人物骨架按原曲线解算器的关节比例统一适配到 `.9` 比例，保留校准后的世界旋转及髋、肩、头位移，调整袖甲和腿甲的长度。原包武器沿 `+Y`，本项目模型沿 `-Y`，只在武器挂点进行轴向校正。原始腾身和身体起伏保留，脚底实际穿地才作高度修正。

## 时序、移动与反馈

普通攻击使用原包五式游标。攻击按 `.24 + atkspd` 播放，恢复固定 `.24`；刀系和重兵初始 `atkspd=.02`，双刀为 `-.01`。攻击切入排队恢复时保留原版行为：恢复从零开始，不跨越该帧的余量。恢复期间下层移动继续运行，新攻击直接替换上层恢复。

待机、走路、跑步使用各自原始片段，原始分量混合后才归一化旋转，移动切换保留 `.3` 秒淡入。跑步原始播放速率 `.6`，慢走为 `speedFactor/7.5 + .2`。取消旧版把慢走统一显示成跑步的处理，以及旧版固定握点覆盖手臂步态的处理。

攻击前冲和后续发力使用原包质量、阻尼和施力值，位移继续受场景实体、活敌人与场地边界阻挡。演武在固定展示位置播放完整身体动作；实战执行惯性前冲。

伤害发射器保留原包四帧、20 fps 时序，显示后仅第 1、2 帧参与伤害，双刀主、副发射器各自记录命中。v0.14.2 为四种兵器分别制作实物轨迹特效，替换共用刀光与受击形状；短暂视觉尾迹不延长碰撞、不取消发射器。地面压力环在真实锤头触地位置生成并固定世界位置。普通命中不暂停主角或全局时间，镜头继续采用原版水平／竖向位移反馈并按 `dt*10` 返回。

伤害数值仍采用本项目平衡表，末式保持较强伤害；敌方模型碰撞体用本项目实体球体适配原发射器。实物刀刃、锤头扫掠继续驱动场景接触和碎屑，不能用柄身制造敌方伤害。附件没有音频文件，挥击、命中和脚步仍使用本项目合成音效，并接入新动作事件及五式索引。

## 文件与复现

`src/sourceMotion/data.js / curves.js / scales.js / hermite.js / sampler.js` 保存原始曲线及解算器；`catalogue.js / clock.js` 管理五式和独立动作时钟；`rig.js / authored.js` 负责骨架、双刀挂点和自创大锤动作；`combat.js` 管理原式碰撞，`weaponFeedback.js / weaponImpact.js / contact.js` 管理四武器独立视觉和实物轨迹方向，`enemyFinishers.js` 管理真实模型碎裂与分割。`feedback.js / impact.js` 保留原式几何审计与镜头计算。

源码和压缩包的 SHA-256 记录在 `src/sourceMotion/provenance.json`。原始数据与当前渲染适配分开保留：

```bash
node tools/import-source-motion.mjs /path/to/original/src /path/to/src.rar
node src/sourceMotion/verify.mjs /path/to/original/src
```

逐帧比较 24,108 个原始姿势和 909 组原始移动混合，所有帧与挂点数值完全一致，最大误差为零。这项验证针对原始解算器；自创大锤握点和模型适配另由测试覆盖。

旧版原创四式、固定握点和世界脚步锚点的历史测试保存到 `tests/legacy/`；当前原式动作、时钟、握点、接地、控制与碰撞测试在 `tests/`。

## v0.14.1 音效与浏览器验证

`src/audio.js` 为所有 20 式挥击和命中分别调音。刀刃使用短促切击与金属共鸣，大锤使用风压、低频重量和短促石裂，第五式具有独立音色；起手加入低声握柄和衣甲摩擦，腾身落地加入靴底与甲片触地声。

演武入口的真实点击或键盘操作解锁音频，进入战斗前也能听到五式演示。暂停、静音、页面隐藏会停止并释放瞬态声音，恢复与重开保留用户的静音选择；异步挂起与恢复也处理快速切换。

真实 Chromium OfflineAudioContext 检查 49 组声音（20 挥击、20 命中、2 落地砸锤及7种辅助声音）：全部输出有限且非零，最大采样峰值约 `.275`，没有削波。真实点击验证演武声音、暂停、静音、恢复、重开和换武器，未出现 JavaScript 运行错误。

## v0.14.2 独立兵器特效与击杀

四种武器分别观察真实刀刃、锤头的世界位置和姿态，保留原式五式动作与伤害时序：双刀左右短迹分别采样；砍刀使用窄而清楚的刀路；大刀使用更长的钢蓝斩迹与细金色边；大锤使用实体锤头残影、短风压、琥珀火星与灰尘，没有刀光几何。大锤的地面特效在锤头触地后才固定压力环、碎石与裂纹。

普通命中也分兵器：双刀交错短闪、砍刀细切线、大刀宽斩与甲屑、大锤立体压碎闪光及护甲碎片。受击方向从实际武器前后帧求出；竖直砸击保留竖直视觉方向，人物推退仍在地面上解算。

致命刀击对受击瞬间的真实模型作三角形切割并封闭切面，砍刀和大刀保留两段身体，双刀交叉分为四段。大锤将真实模型打成24块身体与护甲碎片，向攻击方向和周围飞散。模型快照保留当时姿势与配色，原角色立即隐藏；独立碎片落地、旋转并淡出，不与旧版尸体下沉或死亡特效叠加。现有伤害、血量、掉落和击杀计数保持原规则。

所有特效使用有限池或数量上限；暂停冻结时间，重开与换关清理实例。大锤在敌人出生时预热静态几何的封口碎片，击杀时按当前骨骼姿态变换、归并成24块；最终碎片将原配色烘焙到顶点颜色，每块只需一个材质。快照只使用自有几何与材质，释放时不影响共享角色资源。实例网格的GPU资源在最终清理时单独释放。最后一击进入胜利界面后，碎片仍继续落地和淡出，击杀与掉落只执行一次。

## v0.14.3 连续重锤与放大刀光

大锤旧柄轨迹对每个中间姿势单独使用 smoothstep，命中处速度归零、跟进后还保留固定持械姿。旧砸地修正会在锤头接近地面时直接夹住倾角；第四式在相邻1ms采样中的头速曾从27.8降至4.1m/s。新五式采用带连续切线的Hermite轨迹，扩大横扫、过顶蓄势、身体转动与随击，最低点后及时反弹收招。完整锤头净空采用平滑高度约束，不硬改倾角；两手仍共同解算在同一柄上。

原式骨盆、头和腿旋转保留；锤柄解算使用原生胸部父级，不再额外叠加一层胸部 Euler 旋转，避免肩父级和手臂世界四元数不同步造成穿体、拉伸和扭形。自定义锤柄在同一源角色坐标中连续采样，双手通过同一根刚性轴求解，最低点用平滑净空约束，接触后及时反弹。原生攻击结束时到达下一式的接柄姿势，避免实战在恢复开始接下一击时跳动；无目标时恢复中仍有小幅余势。五式播放时钟、攻击传感器、声音事件和伤害窗口保持原规则。快速宽弧触地时，地面尘裂使用前后真实锤头底部的触地插值，避免显示帧率改变冲击位置。

刀光从几厘米的刀尖细线改成刀身扫掠形成的宽弧。双刀、砍刀、大刀的弧面沿刀长覆盖约0.72、1.33、1.74米，刀尖额外延伸24%、32%、40%；各自具有渐变主弧、细亮外刃和淡外光，大刀另有金边。三类视觉尾迹分别为.18、.21、.24秒并独立淡出，显示放大不扩大碰撞或延长伤害。大锤仍只使用实体锤头残影和风压。
