## 手机横屏与全屏行为

手机开始或重新开始时，会在音频初始化前同步请求全屏，再尝试 `screen.orientation.lock('landscape')`。进入战斗后，如果浏览器仍未全屏或屏幕未横向，会阻止竖屏／窗口化操作并显示对应提示与重试按钮。Android Chrome 桌面站点模式会结合 Android 平台、触屏和窄屏识别；iPad 与平板不触发。PWA manifest 设为全屏横向；添加到主屏幕后可使用安装态启动。未在实体 Android 设备复现用户报告的问题，本轮仅完成代码修复和生产构建检查。
